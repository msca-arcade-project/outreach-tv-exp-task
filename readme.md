# Readme
This subproject is about building a TV-grade version of the experimental task that will be proposed to a TV show. The point is to ullustrate decision making under distraction, and hopfully it can contribute outreach credits that can be logged to the EU MSCA system for the project.

Requirements:
- main task should be a selection task where the participant presses a key when a target occurs in a stream of non-targets. Could be target=vowel nontarget:consonant or simlar.
- the stream of items should scroll upwards and scrolling speed should parameterised
- plan for using both the original text distractor and image and video distractors - since this will be shown on TV it is likely editors want something flashy
- participants press one key for target, another for non-target, like left, right arrows
- keep progress indicator but plan for a visual bar as well as the text - the experiment won't be used for actual data collection but has to look serious
- experiment should be accessible from an online site and run in a browser to make it easy for the TV people to log on and run - it may run from e.g. a git website
- after the experiment concludes, the stats should be shown in a clear TV friendly way; the editors may e.g. want to have one participant with distraction and one without and compare their results

Notes:
- let's build two clear alternatives the editors can choose from rather than waste time on lots of variations
